# Rebrand: StoryPass → StoryWeaver

Rename the product everywhere it is visible, keeping design, features, and data untouched.

## What changes

- **Header and footer wordmark** — "StoryPass" becomes "StoryWeaver" in the site shell.
- **Page titles and social preview text** — every route's title, description, og:title, og:description across ~30 route files (home, discover, series, chapters, books, play, studio, pricing, wallet, auth, checkout success, notifications, following, creators).
- **Body copy** — in-page mentions such as "Thanks for supporting StoryPass creators", pricing plan copy, auth page copy, studio and subscriber notes.
- **AI prompt text** — the writing-assistant prompts in the AI layer that name the product.
- **Design-system comments** in the stylesheet that reference the old name.

## What stays the same

- Colors, fonts, layout, and components — no visual redesign.
- Database tables, columns, and seeded story data.
- Routes and URLs (the published Lovable URL slug stays unless you ask to change it).
- Paddle products/prices (their internal names live in the payment provider, not the app).

## Notes

- Tone stays identical; only the name string changes, plus any phrasing that reads awkwardly with the new name.
- Optionally I can generate a small "SW" flame-style brand mark and set it as the favicon — say the word and I'll include it.
